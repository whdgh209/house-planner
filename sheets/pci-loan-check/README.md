# 개인 간 차용 및 상환능력 검증 (PCI 세무 리스크 사전 점검)

국세청 PCI(Property·Consumption·Income) 분석 관점에서, 차입자가 **만기 시점에 차용
원금을 상환할 현금흐름 체력이 있는지**를 시뮬레이션하고 판정하는 Google Sheets 템플릿.

- 시트명: `PCI_차용검증`
- 바로 쓰는 파일: [`PCI_차용검증.xlsx`](./PCI_차용검증.xlsx) — 권장
- Apps Script 버전: [`PCI_차용검증.gs`](./PCI_차용검증.gs)
- 배치: A열 = 항목, B열 = 값/수식, C열 = 비고 (8·11번 섹션만 A~I열 표 형태)

---

## 0. 빠른 시작

### 방법 A — xlsx 가져오기 (권장)

1. 「부동산」 스프레드시트 열기
2. **파일 → 가져오기 → 업로드**에 `PCI_차용검증.xlsx` 드롭
3. 가져오기 위치를 **"새 시트 삽입"**으로 선택 → 가져오기
4. 노란색 셀(입력값)만 본인 숫자로 교체

수식은 중첩 `IF`와 문자열 연결만 써서 Google Sheets · Excel · LibreOffice에서
동일하게 동작한다 (`IFS`, `TEXTJOIN` 등 호환성 문제가 있는 함수는 사용하지 않았다).

### 방법 B — Apps Script

1. 「부동산」 스프레드시트 열기 → **확장 프로그램 > Apps Script**
2. `PCI_차용검증.gs` 내용 전체 붙여넣기 → 저장
3. 함수 `buildPciSheet` 선택 후 **실행** (최초 1회 권한 승인)

같은 이름의 시트가 이미 있으면 삭제하지 않고 `PCI_차용검증_백업_yyyyMMdd_HHmmss`로
이름만 바꿔 보존한다.

> xlsx에서는 체크박스 대신 `☐ / ☑` 드롭다운을 쓴다 (xlsx에 체크박스 규격이 없음).
> Apps Script 버전은 진짜 체크박스로 생성된다.

수동으로 만들 경우 아래 표의 행 번호를 **그대로** 지켜야 한다. 모든 수식이 절대참조
(`$B$38` 등)로 행 번호에 고정되어 있다.

## 3. 연도별 현금흐름 시뮬레이션 (72~83행, A~I열)

원안의 `연간 잉여 × N년` 단순 곱셈을 대체하는 **구조적 핵심 개선**이다.
급여 상승, 물가 상승, 중도 종료되는 대출, 원금 분할상환을 모두 연도별로 반영한다.

72행: `■ 8. 연도별 현금흐름 시뮬레이션 [자동]`
73행 헤더:

| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| 연차 | 세후 총소득 | 기존 부채상환 | 필수 생활비 | 차용 이자 | 원금 분할상환 | 연간 잉여 | 누적 잉여 | 원금 대비 누적 |

74행(1년차) 수식 — 아래를 83행(10년차)까지 채우기:

```
A74 =1            (A75=2 … A83=10)

B74 =IF($A74>$B$40,"",ROUND($B$62*(1+$B$9)^($A74-1),0))

C74 =IF($A74>$B$40,"",
      $B$23*MIN(12,MAX(0,$B$24-($A74-1)*12))+
      $B$25*MIN(12,MAX(0,$B$26-($A74-1)*12))+
      $B$27*MIN(12,MAX(0,$B$28-($A74-1)*12)))

D74 =IF($A74>$B$40,"",ROUND($B$67*(1+$B$35)^($A74-1),0))

E74 =IF($A74>$B$40,"",ROUND(MAX(0,$B$38-$B$43*($A74-1))*$B$41,0))

F74 =IF($A74>$B$40,"",MIN($B$43,MAX(0,$B$38-$B$43*($A74-1))))

G74 =IF($A74>$B$40,"",B74-C74-D74-E74-F74)

H74 =IF($A74>$B$40,"",G74)                      ← 1년차만
H75 =IF($A75>$B$40,"",N(H74)+G75)               ← 2년차부터 (아래로 복사)

I74 =IF($A74>$B$40,"",IFERROR(H74/$B$38,""))
```

- `C74`의 `MIN(12,MAX(0,잔여개월-(n-1)*12))`가 해당 연도에 실제로 상환하는 개월수다.
- 만기 일시상환 원금은 F열에 넣지 않는다. 그건 비용이 아니라 **H열 누적액과 비교할
  대상**이기 때문이다.
- `N()`은 위 셀이 `""`일 때 0으로 처리해 `#VALUE!`를 막는다.

**B89 (최종 판정)**

```
=IF(NOT(ISNUMBER($B$87)),"입력 확인 필요",
  IFS(
    AND($B$87>=$B$86*1.2,$B$92>=0), "✅ 상환 여유 충분",
    AND($B$87>=$B$86,    $B$92>=0), "⚠ 상환 가능 (주의 요망)",
```

**B88 서식**: `0.0%` / **조건부 서식**: ≥120% 녹색, <100% 적색.

## 6. 성과급 민감도 분석 (104~108행, A~D열)

성과급은 변동 재원이라 "120% 버퍼"라는 단일 숫자로 뭉뚱그리기보다 반영률별로 판정을
갈라 보는 편이 실제 의사결정에 쓸모 있다.

104행: `■ 11. 성과급 민감도 분석 [자동]`
105행 헤더: `성과급 반영률 | 누적 잉여액 | 버퍼율 | 판정`
106~108행: A열 = `0%`, `50%`, `100%`

```
B106 =IF(NOT(ISNUMBER($B$87)),"",ROUND($B$87-($B$10-$A106)*ROUND($B$7*(1-$B$20),0)*
      IF($B$9=0,$B$40,((1+$B$9)^$B$40-1)/$B$9),0))

C106 =IF(OR(NOT(ISNUMBER(B106)),$B$86=0),"-",B106/$B$86)

D106 =IF(NOT(ISNUMBER(B106)),"",
      IFS(B106>=$B$86*1.2,"✅ 여유 충분",B106>=$B$86,"⚠ 가능(주의)",TRUE,"❌ 부족"))
```

성과급이 누적 잉여에 선형으로 작용한다는 점을 이용해, 기준 시나리오에서
`(기준 반영률 − 시나리오 반영률) × 성과급 세후액 × 연금합계계수`만큼 차감한다.
`IF($B$9=0,$B$40,((1+$B$9)^$B$40-1)/$B$9)`가 급여상승률 g에 대한 등비합
`Σ(1+g)^(n-1)`이며, g=0일 때의 0으로 나누기를 막는다.

## 9. 원안 대비 변경한 것과 그 이유

| # | 변경 | 이유 |
|---|---|---|
| 1 | 세율·요율을 전부 입력 셀로 분리 (13~20, 46~49행) | 원안은 17~18%, 35%를 수식에 하드코딩. 고시 요율은 매년 바뀌고, 소명 자료라면 근거가 셀로 보여야 한다 |
| 2 | 4대보험을 항목별로 분해 + 국민연금 상한 `MIN()` 적용 | "약 17~18%"는 고연봉일수록 과대계상된다. 국민연금은 기준소득월액 상한이 있어 실효율이 떨어진다 |

| 6 | **이자 원천징수 27.5% (49·65·66·101·116행)** | 원안에 완전히 빠져 있었다. 개인 간 금전대차 이자는 비영업대금의 이익으로 차입자가 원천징수·신고 의무를 진다. 이 신고 이력이 차용 사실의 가장 강력한 증거다 |

| 8 | 원금 분할상환 옵션 (42·43행) | 만기 일시 + 무이자는 증여 추정이 가장 강한 조합이다. 분할 시나리오를 돌려볼 수 있어야 한다 |
| 9 | 성과급 민감도 표 (104~108행) | 원안의 "120% 버퍼"는 성과급 변동성에 대한 거친 대용치다. 반영률 0/50/100%로 직접 갈라 보는 게 낫다 |
| 10 | 소득 대비 차입 배수·생활 DSR (90·91행) | 국세청이 실제로 먼저 보는 직관적 지표 |
| 11 | 소명 실행 체크리스트 (110~120행) | 시트가 아무리 좋아도 계좌이체·원천징수 이력이 없으면 소용없다 |
