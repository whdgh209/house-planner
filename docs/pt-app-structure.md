# PT 관리 앱 구조 설계

> 트레이너가 캘린더, 세션일지(운동일지), 상담일지, 계약, 잔여 회차를 한곳에서 관리하고,
> 원하는 회원에게는 **본인 운동일지만** 볼 수 있는 링크를 주는 웹앱(PWA)입니다.

## 1. 현재 방식과 바뀌는 점

| 지금 | 앱에서 |
|---|---|
| 구글 캘린더에 회원 이름으로 일정 등록 (색으로 센터 구분) | 앱 캘린더에 예약. 예약을 누르면 바로 세션 기록으로 이어짐 |
| 삼성노트 PDF 세션카드에 손글씨 기록과 서명 | 세션 기록 화면에서 입력하고 화면에 손가락으로 서명 |
| 카톡으로 "6.29 운동 / 1.케이블 암풀다운(cable arm pull down)…" 직접 타이핑 | 종목 자동완성으로 입력하면 **같은 형식의 카톡 문구가 자동 생성**됨. 복사하거나 공유 버튼으로 전송 |
| 상담일지·계약서 PDF를 센터별 폴더에 보관 | 회원 상세 화면의 탭으로 보관 |
| 잔여 횟수와 만료일(10회 기준 40일)은 머릿속으로 계산 | 자동 계산하고, 임박하면 홈 화면에 표시 |
| 종료 회원은 "종료" 폴더로 이동 | 회원 상태를 `종료`로 바꾸면 보관 목록으로 이동 |

## 2. 사용자와 권한

| 사용자 | 접속 방법 | 할 수 있는 것 |
|---|---|---|
| **트레이너** | 구글 로그인 (트레이너 계정 1개만 허용) | 전체 조회·작성·수정 |
| **회원** (원하는 사람만) | 카톡으로 받은 **개인 비밀 링크**. 로그인 없음 | 본인 운동일지, 잔여 회차, 기간, 다음 예약 **읽기만** |

회원 공유는 가입 없이 링크로 합니다.
- 회원마다 추측할 수 없는 긴 랜덤 토큰 링크를 만듭니다 (`…/m.html#k8Zq2…`).
- 링크로 보이는 문서에는 **이름(성 제외 가능)과 운동기록만** 들어갑니다. 연락처, 상담일지, 병력, 결제 정보는 절대 들어가지 않습니다.
- 트레이너가 공유를 끄거나 링크를 재발급하면 이전 링크는 바로 막힙니다.
- 나중에 필요하면 회원 구글 로그인 방식으로 올릴 수 있습니다.

## 3. 화면 구조

### 트레이너 앱 (하단 탭 4개)

```
┌ 홈(오늘) ──────────────────────────────────────┐
│ 오늘 수업: 20:00 김OO (롯데캐슬) 4/10회           │
│ ⚠ 기록 안 한 수업 2건                            │
│ ⚠ 만료 임박: 박OO D-5 (잔여 3회)                  │
│ ⚠ 재등록 대상: 이OO 잔여 1회                      │
└────────────────────────────────────────────────┘
① 홈   ② 캘린더   ③ 회원   ④ 설정
```

**① 홈**
- 오늘과 내일 수업 목록. 누르면 세션 기록으로 이동
- 알림 카드: 미작성 일지, 만료 임박(D-7), 잔여 1~2회(재등록 안내), 계약 만료로 소멸될 회차

**② 캘린더**
- 주간 보기(지금 쓰는 구글 캘린더와 비슷한 모양)와 월간 보기
- **센터별 색상** (예: 구서 롯데캐슬 = 초록, 명륜 아이파크 = 노랑)
- 빈 칸을 누르면 예약 추가 (회원 선택, 시간, 반복 예: 매주 월·수 20:00)
- 예약을 누르면 `수업 완료 → 일지 작성` / `불참 처리` / `변경` / `취소`
- 공휴일 표시

**③ 회원**
- 상단 탭: `구서 롯데캐슬` `명륜 아이파크` `종료`, 그리고 검색
- 목록 카드: 이름, 잔여 회차(4/10), 만료일, 다음 예약
- **회원 상세** 탭 구성:
  - `요약`: 잔여 회차, 기간(시작일부터 만료일, D-day), 운동목적, 다음 예약, 공유 링크 상태
  - `세션일지`: 날짜별 목록(1회차부터 10회차까지 세션카드 형태로도 보기)
  - `상담일지`: 상담 기록 (종이 양식과 같은 항목)
  - `계약`: 신규·재등록 이력, 회차, 금액, 기간, 동의 항목
  - `공유`: 공유 켜기·끄기, 링크 복사, 카톡으로 보내기, 링크 재발급

**세션 기록 작성 화면** (가장 자주 쓰는 화면)
```
6.29 (월) 김OO · 5회차 / 10
운동 제목(선택): 등운동, 흉추들고
1. [케이블 암풀다운      ] 메모: [              ]
2. [랫풀다운(뉴트럴그립 와이드)] 메모: [          ]
   세트/무게(선택): 3세트 × 12회 / 30kg
+ 종목 추가   ↕ 순서 변경
트레이너 서명 [   ]   회원 서명 [   ]
[저장]  [카톡 문구 복사]  [공유하기]
```
- 종목 이름을 입력하면 한글·영문 이름이 함께 자동완성됩니다 (`랫` 입력 시 `랫풀다운(lat pull down)`)
- 종목별 메모 가능 (예: "팔꿈치 몸통에 붙인채로")
- 세트, 횟수, 무게는 **선택** 입력입니다. 입력해 두면 나중에 성장 그래프를 볼 수 있습니다
- `카톡 문구 복사`를 누르면 지금 보내는 형식과 똑같이 만들어집니다:
  ```
  6.29 운동(등운동, 흉추들고)
  1.케이블 암풀다운(cable arm pull down)
  2.랫풀다운(뉴트럴그립 와이드 lat pull down)
  …입니다
  ```
- 공유가 켜진 회원이면 문구 끝에 "지난 기록 보기: 링크"가 붙습니다

**④ 설정**
- 센터 관리 (이름, 색상, 입금 계좌, 사용·종료 여부)
- 종목 사전 (한글, 영문, 부위, 기본 메모). 처음에는 카톡 기록에 있는 종목으로 채워 둡니다
- 계약 규칙 기본값 (10회 = 40일, 변경 마감 3시간 전)
- 데이터 백업 내보내기 (JSON 또는 엑셀)

### 회원 보기 페이지 (링크, 읽기 전용)

```
┌ OO님의 운동일지 ─────────────┐
│ 잔여 6회 / 10회  · 만료 10.13 │
│ 다음 수업: 10.2(금) 20:00    │
├─────────────────────────────┤
│ 9.21 (5회차)                 │
│  1. 카프레이즈(calf raise)    │
│  2. 백익스텐션 …              │
│ 9.17 (4회차) …               │
└─────────────────────────────┘
```
- 최신순 카드, 종목 검색 ("랫풀다운 언제 했지?")
- 홈 화면에 추가 안내 (앱처럼 아이콘 생성)

## 4. 데이터 구조 (Firebase Firestore)

```
gyms/{gymId}
  name, color, bankAccount, active

members/{memberId}
  name, gender, birth, phone, gymId, unit(동/호수)
  status: active | ended
  goal[], experience, medicalHistory, memo
  share: { enabled, token }

members/{memberId}/consultations/{id}      ← 상담일지
  date, goal[], experience, medical, lifestyle, notes, wishes

members/{memberId}/contracts/{id}          ← 계약(신규/재등록)
  type: new | renew
  startDate, endDate(자동: 10회 → +40일), sessionCount, price
  agreed: { period, sign, cancel3h, refund }, signedAt

members/{memberId}/sessions/{id}           ← 예약 + 세션일지 (같은 문서)
  contractId, no(회차), start, durationMin
  status: booked | done | noshow | canceled
  title("등운동, 흉추들고")
  exercises: [{ name, nameEn, note, sets?, reps?, weight? }]
  trainerSign, memberSign (서명 이미지 데이터)

exercises/{id}                             ← 종목 사전
  name, nameEn, bodyPart, defaultNote

shares/{token}                             ← 회원 공개용 사본 (민감정보 없음)
  displayName, remaining, total, endDate, nextSession
  sessions: [{ date, no, title, exercises:[{name,nameEn,note}] }]
```

핵심 설계:
- **예약과 세션일지를 같은 문서로** 둡니다. 캘린더에 예약하면 `booked`, 수업 후 기록하면 `done`이 되어 이중 입력이 없습니다.
- **잔여 회차 = 계약 회차 − (done + noshow 개수)**. 3시간 전 규정에 따라 불참도 차감합니다.
- **`shares`는 트레이너가 저장할 때마다 자동 갱신되는 요약 사본**입니다. 회원 링크는 이 문서만 읽을 수 있습니다.

### 보안 규칙 (요지)

```
match /shares/{token} {
  allow get: if true;          // 토큰을 아는 사람만 1건 조회
  allow list: if false;        // 목록 조회 금지
  allow write: if isTrainer();
}
match /{doc=**} {
  allow read, write: if isTrainer();   // 나머지는 트레이너만
}
```

## 5. 기술 구성 (전부 무료)

| 항목 | 선택 |
|---|---|
| 화면 | HTML + JavaScript (빌드 도구 없이, 기존 집 플래너와 같은 방식) |
| 파일 | `index.html` (트레이너용), `m.html` (회원 보기용), `manifest.json`, `sw.js` (홈 화면 설치) |
| 로그인 / DB | Firebase Auth (구글) + Firestore, 무료 요금제 |
| 호스팅 | GitHub Pages 또는 Firebase Hosting |
| 서명 | `<canvas>` 손가락 서명을 이미지로 저장 |
| 카톡 전송 | 클립보드 복사 + Web Share API (공유 버튼을 누르면 카카오톡 선택) |

> ⚠ 회원 개인정보(이름, 연락처, 병력 등)는 **절대 저장소(코드)에 넣지 않습니다.** Firestore에만 저장하고 보안 규칙으로 잠급니다.
> 병력 같은 건강정보는 개인정보보호법상 민감정보이므로 상담 시 회원 동의를 받고 필요한 만큼만 적습니다.

## 6. 기존 기록 옮기기

- **카톡 운동일지 붙여넣기 변환**: 카톡 대화 텍스트를 붙여넣으면 `6.15 운동 / 1.백익스텐션(back extension)` 형식을 인식해서 세션 기록으로 자동 변환합니다. 과거 기록을 회원 페이지에 바로 채울 수 있습니다.
- 진행 중인 회원만 계약(시작일, 회차)과 지금까지 회차를 입력합니다. 종료 회원은 삼성노트에 그대로 둡니다.
- 구글 캘린더의 다음 주 예약은 처음 한 번만 앱에 옮겨 입력합니다(또는 3단계 연동).

## 7. 개발 단계

| 단계 | 내용 | 결과 |
|---|---|---|
| **1단계** | 센터·회원 관리, 계약(회차·기간 자동 계산), 세션일지 작성, 종목 자동완성, 카톡 문구 생성, 회원 공유 링크 | 카톡 보내기가 편해지고 회원이 기록을 볼 수 있음 |
| **2단계** | 캘린더(주간·월간, 반복 예약, 센터 색상), 예약에서 일지로 연결, 홈 알림(미작성, 만료 임박), 상담일지 | 구글 캘린더와 삼성노트를 대체 |
| **3단계** | 전자서명, 카톡 기록 가져오기, 세트·무게 성장 그래프, 백업 내보내기, (선택) 구글 캘린더 연동 | 완성도 향상 |
